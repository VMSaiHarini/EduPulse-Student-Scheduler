Connect WhatsApp Notifications via N8N

Follow these steps to set up automated WhatsApp messages for class reminders

1

Install N8N

Run N8N locally or use N8N cloud. For local install:

npm install -g n8n
n8n start

Or use Docker:

docker run -it --rm --name n8n -p 5678:5678 -v ~/.n8n:/home/node/.n8n n8nio/n8n
2

Create a New Workflow

Open N8N at http://localhost:5678 → Click "New Workflow"

Name it: "Student Class Reminder"

3

Add Webhook Trigger Node

Search for "Webhook" node → Add it → Set:

  • HTTP Method: POST
  • Path: class-reminder
  • Authentication: None (or Header Auth)

Copy the webhook URL — you'll paste it in EduPulse Settings.

http://localhost:5678/webhook/class-reminder
4

Add WhatsApp Node

Search for "WhatsApp Business Cloud" or "Twilio":

Option A — WhatsApp Business API (Meta):

  • Connect your Meta Business Account
  • Set "To" field: {{ $json.whatsapp_number }}
  • Set "Message": {{ $json.message }}

Option B — Twilio WhatsApp:

  • Add Twilio credentials
  • Use "Send Message" node
  • From: whatsapp:+14155238886 (Twilio sandbox)
  • To: whatsapp:{{ $json.whatsapp_number }}
  • Body: {{ $json.message }}
5

The Webhook Payload

EduPulse sends this JSON to your webhook:

{ "student_name": "Arjun Sharma", "whatsapp_number": "+919876543210", "message": "📚 Class Reminder! Maths starts in 5 mins...", "subject": "Mathematics", "start_time": "16:00", "room": "Room 101", "teacher": "Mr. Sharma", "type": "class_reminder" }
6

Connect to EduPulse

Go to Settings → Notification Settings and:

  • Paste your N8N webhook URL
  • Enter your WhatsApp number with country code
  • Click "Test Notification" to verify
✓

Done! You're All Set 🎉

EduPulse checks your schedule every minute. When a class is 5 minutes away, it sends the webhook to N8N, which delivers the WhatsApp message automatically!
